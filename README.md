# Clarm Android 正式版

普通闹钟、三班倒排班、真实日出日落与月相、公历／农历重要日子提醒。

## 下载和安装

前往 [最新正式版](https://github.com/ljy7727/clarm-releases/releases/latest)，下载唯一的 `clarm-版本.apk`。支持 Android 8.0 及以上；无需 GitHub 登录。

2.0.0 建立新的固定正式签名。旧测试版首次切换必须卸载旧包，卸载会清除旧设置；建议先记录闹钟。之后正式版可通过应用内「设置 → 软件更新」检查、下载并由 Android 确认安装。不会静默安装。

## 使用提示

- 普通闹钟支持单次、每天和自选星期；倒班按夜班、中班、早班逐周轮换。
- 响铃时按电源／锁屏键暂停，默认 1 分钟后重响，可改为 2 分钟；每轮可以重复。停止或上滑结束本次提醒。
- 选中的节日或生日恰好提前 7 天在设定时间提醒；支持公历和农历。
- 首次安装请检查精确闹钟、通知、锁屏与电池权限，并使用试响功能验证。厂商系统后台策略可能影响提醒。
